######
Design
######

The design is a class model (``src/spl/``) and a pin top that connects it to
the Wishbone and UART pins (``src/spl-rtl/``). The ``wb`` view simulates the
pin top as written; the ``rtl`` view simulates its lowered netlist, module
``fw_uart16550_spl``. See :doc:`/design/index` for the design and
:doc:`/design/fw-impl` for how it was built.
